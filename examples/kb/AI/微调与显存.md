# 微调与显存

## LoRA 是什么

冻结原权重 W，只训练两个小矩阵 A 和 B，前向变成 `W·x + (B·A)·x`。
参数省在 rank r 很小：原矩阵 d×d，LoRA 只有 d×r + r×d。
常见取值 r=8 或 16，lora_alpha 一般取 2r；r 越大表达能力强但越容易过拟合。
推理时可以合并回原权重（`merge_and_unload`），所以**不增加推理开销**。
常见问法：LoRA 原理、r 取多少合适、lora_alpha 是什么、合并后推理会变慢吗

## QLoRA

把基座模型量化成 4-bit NF4 之后再挂 LoRA 训练，所以 7B 模型能在单张 24GB 显卡上微调。
它的三个关键点：4-bit NF4 量化、双重量化（对量化常数再量化）、分页优化器（显存峰值时把
优化器状态换到内存）。
常见问法：24G 显卡能微调多大模型、QLoRA 和 LoRA 区别、4bit 会不会掉点

## 显存怎么估

推理：参数量 × 每参数字节。FP16 是 2 字节，所以 7B ≈ 14GB；INT8 ≈ 7GB；INT4 ≈ 3.5GB。
训练（Adam + 混合精度）大致 16 字节/参数：fp16 权重 2 + fp16 梯度 2 + fp32 主权重 4 +
Adam 的两个状态 8。所以 7B 全参微调要 100GB 以上，必须多卡或换 LoRA。
另外还要算激活值和 KV cache，实际比这个估算再高一截。
常见问法：7B 模型要多少显存、FP16 多大、全参微调要几张卡、显存怎么估算

## KV cache 怎么算

公式：2 × 层数 × 头数 × 每个头的维度 × 序列长度 × batch × 每元素字节数
（2 是因为 Key 和 Value 各存一份）。
它对显存是线性增长，而且和序列长度成正比 —— 长上下文推理时它常常比权重还占地方。
常见问法：KV cache 多大、长上下文为什么爆显存、KV cache 公式

## 量化档位怎么选

FP16/BF16 是训练和默认推理；INT8 基本不掉明显效果；INT4（GPTQ/AWQ）大约掉 1~3 个点，
但显存只剩四分之一。要精度优先用 BF16，要省钱/本地跑用 INT4。
常见问法：INT8 和 INT4 差多少、量化会掉点吗、本地部署选哪个量化

## 学习率怎么设

全参微调常用 1e-5 ~ 5e-5；LoRA 要比全参大一个量级，常用 1e-4 ~ 3e-4。
warmup 一般占总步数的 3%~10%，cosine 衰减是主流。
常见问法：微调学习率设多少、LoRA 学习率为什么更大、warmup 设多少

微信 AI 聊天辅助工具 —— 使用说明
============================================================

这是什么
------------------------------------------------------------
读你电脑上已经打开的 PC 微信窗口里的对话内容，用 AI 生成几条
「你可以直接发出去」的回复草稿，显示在自己的小窗口里。你看着挑一条，
自己复制、自己粘贴、自己按回车。

⚠️ 它不会替你发消息，也不会碰你的微信：
   · 不模拟键鼠、不点击微信、不自动复制粘贴
   · 不读写微信数据库、不注入进程、不 hook 网络
   · 不自动发送任何消息
   全程只读微信窗口「已经显示出来的内容」。


怎么用
------------------------------------------------------------
1. 双击   微信AI助手.exe

   第一次 Windows 可能弹「Windows 已保护你的电脑」，
   点「更多信息」→「仍要运行」即可。
   那是因为程序没有买代码签名证书，不是病毒。

2. 打开 PC 微信，随便点开一个聊天。
   小窗口会自己贴到微信旁边。

3. 按   Ctrl+Alt+Q   或者点小窗口上的【生成建议】，
   它会读出当前这一屏的对话，给你三条候选回复。

4. 点任意一条卡片 = 复制到剪贴板。
   然后自己去微信里 Ctrl+V、回车。

窗口上的按钮：
   生成建议     读对话 + 让 AI 写回复（会花 token）
   只看对话     只把当前这一屏读出来给你看（不花 token）
   看提示词     看这一次到底给模型发了什么
   设置         AI 接口 / 人设 / 每个会话单独配置 / 外观……
   ✕            隐藏窗口

   ⚠️ 按了 ✕ 窗口只是藏起来，程序还在跑（右下角托盘里有图标）。
      右键托盘图标可以【显示悬浮窗】/【退出】。


第一次要填 API Key
------------------------------------------------------------
本程序自己不带 AI 能力，要用你自己的接口。

打开【设置 → AI 接口】，把 API Key 填进去，点【测试连接】确认能用，保存。

出厂时「接口地址」和「模型」都是空的 —— 本程序不替你选服务商。
三样（接口地址 + Key + 模型）齐全才会真发请求，缺哪样状态行会点名。

以 DeepSeek 为例（只是举例，用哪家以那家的文档为准）：

   接口地址   https://api.deepseek.com
   模型       deepseek-chat

⚠️ 不填 Key 也能用：它照常读取和记录对话，只是生成建议时会提示
   「未配置 api_key」。


文件都在哪
------------------------------------------------------------
都在 exe 旁边，可以直接看、可以直接改：

   config.yaml     出厂默认配置（带中文注释）。
                   程序永远不会写它 —— 想改默认值就改这里。
   secrets.yaml    你的 API Key（在设置界面里填的话会自动写到这里）。
                   ⚠️ 别把这个文件发给别人。
   state/          运行数据：
                     settings.json   设置界面里改过的值
                     history.db      消息表（口吻样本 / AI 标记）
                     screens.db      屏快照（上下文的顺序）
                     state.json      会话表
   logs/app.log    运行日志。

⚠️ 整个文件夹可以整体搬走（换电脑、换目录都行），配置和数据跟着走。
   但不要只把 exe 单独拖出来 —— 那样配置和数据就找不到了。


系统要求
------------------------------------------------------------
   Windows 10 / 11 64 位
   PC 微信 4.x（实测 4.1.13.65）
   不需要装 Python，依赖都打进去了


出问题了
------------------------------------------------------------
· 双击没反应 / 一闪而过 —— 看 logs\app.log，最后几行就是原因
· 小窗口不出现 —— 看右下角托盘里有没有图标，右键 →【显示悬浮窗】
· 生成建议报「未配置 api_key」—— 去设置里填 Key
· 提示「热键注册失败」—— 多半已经有一个实例在跑，先在托盘里找找
· 群里认不出谁是谁 —— 群聊昵称靠截图 OCR，慢且不总是准，属正常
· Ctrl+Alt+Q 按了没反应 —— 可能被别的软件占了，去设置里换一个键


它是怎么工作的（想了解的话）
------------------------------------------------------------
微信 4.x 是 Qt 写的，用 Windows 的 UI Automation 接口就能读到消息文本，
不需要破解、不需要注入。发送者是自己还是别人靠气泡位置判断（左=别人、
右=自己）；群聊昵称靠对消息行截图做 OCR，并要求同一个名字在同一会话里
复现两次才认。

记录分两个库：一个记「看到过哪几屏」（用来还原上下文顺序），一个记
「一条条消息」（用来学你平时的说话口吻）。两个库都不花 token，
只有进提示词的条数和字数才花钱。
